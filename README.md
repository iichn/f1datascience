# f1datascience
# Анализ телеметрических данных бортовых датчиков гоночных автомобилей и прогнозирование результатов заездов в чемпионате Formula 1

Направление подготовки: **09.04.04 «Программная инженерия»**  
Санкт-Петербургский политехнический университет Петра Великого (СПбПУ)

---

## Описание проекта

Проект посвящен разработке распределенной системы сбора, хранения и аналитической обработки высокочастотной телеметрии интернета вещей (IoT) и временных рядов с бортовых датчиков автомобилей в чемпионате Formula 1. 

Основная цель работы — исследование факторов снижения темпа болидов, выявление паттернов пилотирования, автоматический поиск аномалий в работе агрегатов и построение моделей машинного обучения для кластеризации автодромов и прогнозирования результатов гонок.

---

## Задачи анализа

В рамках проекта решаются задачи статистического анализа (Business Intelligence) и интеллектуального анализа данных (Data Science):

1. **Оценка темпа износа шин и анализ влияния пройденной дистанции на падение скорости автомобиля по ходу заезда.**  
   *Анализ динамики деградации составов резины и расчет темпа потери времени с каждым пройденным кругом.*
2. **Сравнительный анализ стиля вождения спортсменов внутри одной команды по скорости прохождения поворотов и моментам нажатия педалей газа и тормоза.**  
   *Сопоставление телеметрических профилей гонщиков на конструктивно идентичных автомобилях.*
3. **Алгоритмический поиск аномалий и потенциальных технических неполадок автомобиля по показаниям бортовых датчиков скорости и оборотов двигателя.**  
   *Применение методов поиска статистических выбросов для автоматического выявления сбоев, пробуксовок и резких потерь темпа.*
4. **Кластеризация гоночных трасс методами машинного обучения по средней скорости движения, количеству резких торможений и доле прямых участков.**  
   *Обучение без учителя (K-Means) на агрегированных характеристиках автодромов для автоматической сегментации трасс по профилю сложности.*
5. **Построение модели машинного обучения для прогнозирования итоговой позиции гонщика на финише по показателям начальных кругов заезда и погодным условиям.**  
   *Обучение с учителем (регрессионные модели / градиентный бустинг) для оценки финального результата на основе ранней телеметрии.*

## Набор данных (Dataset)

* **Источник данных:** Официальный поток хронометража и телеметрии Formula 1 Live Timing API (клиент `FastF1`) и база метаданных соревнований Ergast Developer API.
* **Тип данных:** Полуструктурированные данные (высокочастотные временные ряды, GPS-координаты и логи датчиков в форматах JSON и CSV).
* **Объем выборки:** Сезоны 2022–2024 гг. Общий объем собранных сырых данных превышает **4.5 ГБ** (более 4 000 000 записей замеров).

### Фиксируемые параметры датчиков:
| Параметр | Описание | Единица измерения |
| :--- | :--- | :--- |
| `Date` / `Time` | Точная временная метка замера | `datetime` / `timedelta` |
| `Speed` | Текущая линейная скорость болида | км/ч |
| `RPM` | Обороты коленчатого вала двигателя | об/мин |
| `nGear` | Выбранная передача коробки передач | 1–8 |
| `Throttle` | Степень нажатия педали газа | % (0–100) |
| `Brake` | Нажатие педали тормоза | бинарный флаг (0/1) или % |
| `DRS` | Статус системы снижения лобового сопротивления | целочисленный статус |
| `X`, `Y`, `Z` | Пространственные координаты болида на трассе | условные единицы GPS/трекинга |

## Архитектура проектируемой системы

Система построена по модульному масштабируемому принципу в соответствии с требованиями ETL-пайплайна:

```text
[ F1 Live Timing API / Ergast ]
               │
               ▼
   [ Модуль сбора (Python / FastF1) ]
               │ (пакетная / потоковая передача)
               ▼
   [ Брокер сообщений (Apache Kafka) ]
               │
               ▼
   [ Распределенное хранилище (HDFS / NoSQL MongoDB) ]
               │
               ▼
   [ Модуль обработки (Apache Spark: Spark SQL + Spark MLlib) ]
               │
               ▼
   [ Модуль визуализации (Plotly / Streamlit Dashboard) ]
