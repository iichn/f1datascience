# Задача 2. Сравнение стиля вождения напарников по команде

Сравниваются лучшие круги квалификации двух пилотов одной команды на одном этапе:
скорость прохождения поворотов, точки начала торможения и выхода на полный газ.

## Методика

1. **Spark (`task2_spark.py`)** — чтение телеметрии квалификаций `*_Q_telemetry.csv`:
   - лучший круг каждого пилота — `Window` + `row_number()`; круги медленнее 107% от лучшего на этапе отбрасываются;
   - метрики стиля по дистанции круга (`lag` / `lead`): доля «газа в пол» (≥ 98%), торможения, наката
     (газ < 5% без тормоза), число зон торможения и переключений передач, макс. и средняя скорость.
2. **Сравнение по поворотам** — круги напарников переводятся на общую сетку с шагом 5 м,
   повороты находятся как локальные минимумы скорости на круге более быстрого пилота (`scipy.signal.find_peaks`).
   Для каждого поворота: минимальная скорость, начало торможения (м до апекса), выход на газ (м после апекса),
   выигрыш времени на участке ±400 м. Повороты делятся на медленные (< 130 км/ч), средние и быстрые (> 200 км/ч).
3. **Сезонная сводка по паре** — счёт квалификаций, медианный разрыв, средние дельты,
   парный критерий Уилкоксона для разницы скорости в поворотах (p < 0.05 — различие значимо).

Все дельты считаются как **Driver1 − Driver2**, пилоты в паре упорядочены по алфавиту.

## Запуск

```powershell
# Полные данные (после выгрузки квалификаций в data/raw_telemetry):
python bin/run_loader.py --year 2022 --session Q --all-races
python data_processor/2/task2_spark.py

# Облегчённый сэмпл из репозитория (лучшие круги всех пилотов, 3 этапа 2022):
python data_processor/2/task2_spark.py --samples

# Дашборд
streamlit run dashboard/2/app.py
```

Сэмпл `samples/sample_task2_*` создаётся скриптом `make_task2_sample.py` (обычные сэмплы содержат
только одного пилота, поэтому для сравнения напарников не подходят).

**Windows:** нужна папка `hadoop/bin` с `winutils.exe` и `hadoop.dll` (как для задачи 5).
Если в пути к проекту есть кириллица, Spark не запускается (`JAVA_GATEWAY_EXITED`) —
создайте ссылку с латинским путём и укажите `SPARK_HOME`:

```powershell
New-Item -ItemType Junction -Path E:\f1ds -Target "<путь к проекту>"
cd E:\f1ds
$env:SPARK_HOME = "E:\f1ds\.venv\Lib\site-packages\pyspark"
```

## Ограничения

- В данных загрузчика нет признака аннулированных кругов (track limits), поэтому лучший круг может быть удалённым.
- Если напарники выбыли в разных сегментах квалификации, их лучшие круги показаны в разное время при разном состоянии трассы.
- Сэмпл (3 этапа) годится для демонстрации; выводы о стиле нужно делать на полном сезоне.
